# Healthy Futures site knowledge vault

For work on this repository, use `vault/` (relative to the repository root) as the project knowledge base.

- Before site work, read `vault/Home.md`, `vault/Project Log.md`, `vault/Tasks.md`, and the notes relevant to the task.
- Verify notes against current code and the user's latest instructions. Distinguish user-confirmed production behavior from locally verified behavior. The user confirms Google Sheets/email delivery is already working in production.
- After meaningful site changes, decisions, or validation, update the relevant notes and append a concise dated entry to `Project Log.md`. Keep `Site Map.md` and page notes accurate when pages change. Update `Tasks.md` for tasks actually requested; do not invent work.
- Preserve user-written notes and existing content. Never store credentials, secret endpoint URLs, or personal registration records in the vault.
- Vault edits do not deploy the website. Do not claim background synchronization or access to a separate local Obsidian copy.
- If the vault is missing, report that fact; do not claim to have consulted or updated it.
