A project vault for the Healthy Futures website, maintained by Julie Gooding.

- [[Site Map]] — pages and their source files
- [[Architecture]] — how the website works
- [[Local Development]] — run and check the site
- [[Calendar Operations]] — public events and owner access
- [[Registration and Email]] — the working Google Sheets integration
- [[Content Maintenance]] — editing pages, images, and the waiver
- [[Deployment]] — Cloudflare configuration
- [[Project Log]] — decisions and verified observations
- [[Tasks]] — a place to track future work

Repository: [jude11224/nordic-walking](https://github.com/jude11224/nordic-walking)
Vault location: `vault/` inside the repository. Open that folder as an Obsidian vault after cloning or pulling.

Open this folder as a vault in Obsidian. All notes use standard Markdown and internal wiki links; no community plugins are required. These notes document the site; editing them does not publish website changes.

## Agent workflow

The repository root `AGENTS.md` instructs coding agents working on this site to consult this vault and update relevant notes after meaningful work. This applies when the workspace instructions and vault are present. There is no background sync to a separate Obsidian copy.
